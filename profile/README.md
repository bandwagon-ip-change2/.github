## 一、先确认：你的 IP 真的被封了吗？

别急着换，先诊断一下。连不上的原因有好几种：IP 被封是其中一种，但端口被封、本地网络问题、VPS 宕机也都可能导致同样的现象。你花了 $8.79 换了个新 IP，结果发现压根不是 IP 的问题——这种事情真的不少见。

诊断方法很简单，用 **ping.pe** 这个工具，把你的 VPS IP 地址输进去，它会从全球几十个节点同时测试这个 IP 的连通性。

- 如果国外节点都能通，就国内通不了：基本可以确认 IP 被墙了
- 如果国内外都通不了：可能是 VPS 本身宕机，登录控制面板检查
- 如果国内外都能通，就你这边连不上：可能是本地网络或者端口问题

搬瓦工自己也提供一个官方 IP 检测工具，登录 KiwiVM 面板后访问检测页面，点击 "Test Main IP"，如果显示 **IP BLOCKED** 就是被封了，显示 **IP NOT BLOCKED** 就没问题。

确认 IP 真的被封之后，再继续往下看。

## 五、换 IP 之后，还是连不上怎么办？

换完 IP 之后，有人发现还是连不上，别慌，通常是这几个原因：

**1. 本地配置没更新**

新 IP 换了，但你的代理客户端、SSH 配置文件里还填的是旧 IP。把配置里的 IP 地址改成新的就好了。

**2. 等 IP 生效**

偶尔 IP 更换有延迟，稍微等几分钟再试。

**3. 问题根本不是 IP**

如果换了 IP 还是不行，很可能是端口被封了，不是 IP 的问题。这个情况需要另外处理，比如换端口、换协议等。
